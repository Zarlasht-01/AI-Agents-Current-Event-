# AI Model 1 Evaluation Prompt

You are a college instructor evaluating a student group project for a basic computer science course about artificial intelligence.

Please review the project at the links below and evaluate it using the complete grading rubric provided.

**GitHub Repository:** https://github.com/Zarlasht-01/AI-Agents-Current-Event-

**YouTube Video:** https://www.youtube.com/watch?v=IjyOdbhgW8k

## Grading Rubric

Each category is worth 25 points, for a total of 100 points.

### 1. Content & Presentation — 25 points

Evaluate whether:

* The AI topic is recent, preferably within the last 6–12 months.
* The information is accurate and explained in simple, clear language.
* The video is organized and stays within the required 2:30–3:00 minute time limit.
* The group explains why the AI topic matters to society.
* The video ends with a thoughtful discussion question.
* All team members participate in the video.

### 2. GitHub Collaboration — 25 points

Evaluate whether:

* The repository is organized and easy to navigate.
* All team members make commits.
* GitHub Issues, branches, and pull requests are used.
* The README contains the required information, including team names, topic summary, YouTube link, discussion question, and sources.
* The GitHub Discussion board is used for team communication or peer responses.

### 3. AI Evaluation Setup — 25 points

Evaluate whether:

* The group submits the project to 2 different AI models.
* The full prompts are saved and visible in the repository.
* The grading rubric is included in the prompts so the AI models have the necessary context.
* The full AI responses are saved alongside the prompts.
* The prompts are specific and thoughtful rather than vague or generic.

### 4. Reflection Quality — 25 points

Evaluate whether:

* The reflection compares the two AI grading results.
* The group clearly explains whether they agree or disagree with the AI-suggested grades.
* The group reflects on how AI helped or did not help during the research process.
* The reflection is honest, specific, and includes real examples.

## Instructions

Please carefully review the GitHub repository and YouTube video before grading.

Give a score out of 25 for each of the four categories.

Then provide:

1. The score for each category.
2. The total score out of 100.
3. Specific strengths of the project.
4. Specific weaknesses or areas for improvement.
5. A short explanation supporting each score.
6. An overall instructor-style comment.

Do not give points simply because a required file or section exists. Evaluate whether the requirement is actually completed and demonstrates meaningful work.

If something cannot be verified from the repository or video, clearly state that it could not be verified rather than assuming that it was completed.

Be fair and constructive, but grade according to the rubric strictly.
